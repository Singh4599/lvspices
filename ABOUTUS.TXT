PERFORMANCE IS CRITICAL

The website must feel extremely smooth and must not lag on normal laptops or mobile devices.

Follow these strict performance rules:

- target smooth 60fps animations
- animate only transform, opacity and clip-path where necessary
- prioritize translate3d, scale, rotate and opacity
- add will-change only while an element is actively animating
- remove will-change after animation completes
- never animate width, height, top, left, margin or padding continuously
- avoid large blur animations
- avoid backdrop-filter on large areas
- avoid heavy box-shadow animations
- avoid continuously animating dozens of particles
- avoid multiple pinned sections running at the same time
- avoid excessive scrub values
- avoid ScrollTrigger on every tiny element
- group related animations inside a single GSAP timeline
- use gsap.context for every React component
- properly kill timelines and ScrollTriggers during cleanup
- use matchMedia for desktop and mobile animation variations
- initialize Lenis only once globally
- connect Lenis correctly with GSAP ticker
- call ScrollTrigger.update during Lenis scroll
- use lagSmoothing correctly
- avoid React state updates during scroll
- never run animations through setState
- use refs for all animated elements
- use requestAnimationFrame only where genuinely required
- lazy-load below-the-fold images
- preload only the first hero image
- serve AVIF or WebP images
- provide responsive image sizes
- avoid massive full-resolution assets
- use poster images for any video
- pause videos outside the viewport
- use reduced-motion support
- ensure animations degrade gracefully
- use dynamic imports only for genuinely heavy components
- do not overuse client components
- keep static content as server components where possible
- isolate animated sections into small client components
- prevent cumulative layout shift
- define image dimensions and aspect ratios
- refresh ScrollTrigger only after fonts and images are ready
- do not continuously call ScrollTrigger.refresh
- test all animations at 1920px, 1440px, 1024px, 768px and 390px widths
